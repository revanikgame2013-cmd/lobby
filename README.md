# Maniac Lobby — лобби с кнопкой «Играть» (Minecraft 1.21.1)

Две части:

- `plugin/` — плагин для сервера Paper 1.21.1 (вся логика: готовность, роли, лидер, старт).
- `mod/` — клиентский мод Fabric 1.21.1 (красивый экран: игроки в ряд, ✔/✘ над головами, кнопки).

Игроки БЕЗ мода тоже могут играть: им открывается обычное меню-сундук с теми же кнопками.

## Как это работает

1. Игрок нажимает «ИГРАТЬ» (кнопка справа внизу в меню паузы Esc), клавишу P, команду /play
   или ПКМ по компасу «Играть» в 9-м слоте.
2. Открывается экран: все, кто в лобби, стоят в ряд. Над каждым ✔ (готов) или ✘ (не готов).
3. Кнопки: «⟳ Роль» (выживший / маньяк), «✔ Готов / ✘ Не готов», «НАЧАТЬ» (активна только у лидера),
   «НАЗАД [ESC]».
4. Лидер — тот, кто зашёл в лобби первым. Если он вышел, лидером становится следующий.
5. Лидер жмёт «НАЧАТЬ»: играют только готовые, остальные остаются в лобби.
   Если никто не выбрал маньяка, он выбирается случайно среди готовых.

## Установка

### Плагин
```
cd plugin
mvn package
```
Файл `target/ManiacLobby-1.0.0.jar` положите в `plugins/` сервера Paper 1.21.1 и перезапустите сервер.

Команды (для админа, права `maniaclobby.admin`, по умолчанию op):
- `/lobby setlobby` — встать там, куда возвращать после игры
- `/lobby setgame` — встать там, куда телепортировать игроков при старте
- `/lobby end` — завершить игру и снова открыть лобби

Настройки в `plugins/ManiacLobby/config.yml` (макс. игроков, макс. маньяков, минимум готовых).
Для теста в одиночку поставьте `min-ready: 1`.

Свою игру подключайте через событие `LobbyGameStartEvent` (есть список участников с ролями).

### Мод
Нужны Java 21 и Gradle.
```
cd mod
gradle build
```
Файл `build/libs/maniac-lobby-client-1.0.0.jar` положите в `mods/` клиента вместе с Fabric Loader
и Fabric API для 1.21.1. Мод нужен только тем, кто хочет красивый экран.

## Важно

Код написан без возможности скомпилировать его в среде разработки, поэтому при первой сборке
возможны мелкие правки (имена методов в маппингах Yarn, особенно `InventoryScreen.drawEntity`).
Если Gradle или Maven покажут ошибку — пришлите её текст, я исправлю.
